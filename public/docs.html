02 How to use these documents

Three things worth knowing before you dive in.

🌗 Light or dark

Use the toggle at the top right. Your choice is remembered next time, so it always opens the way you left it.

⎙ Save as PDF

Every document has a Save / Print button. That turns the page into a clean PDF you can keep offline or send to someone.

📋 Copy the code

Any code box has a Copy button, so you can paste settings into your own dashboard without retyping them.
