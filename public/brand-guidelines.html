02 The logo

The DO monogram. An interlocking “D” and “O” — for Dammie Optimus — with a solid node at the centre of the O standing for the AI layer.

The three approved lockups

Approved sizes

📏
Minimum size and clear space

Never render the bare monogram below 28px wide — the centre node disappears and the mark reads as a smudge.

Keep clear space of at least the width of the centre node on all sides (that is 1/8 of the mark's width). Nothing — text, image edge or another element — may enter that space.

Rules

✓ Do
  • Use the SVG, always — it is resolution independent
  • Keep the gradient running emerald → cyan, top-left to bottom-right
  • Place the mark on a dark or neutral ground
  • Reuse the exact SVG source below, unmodified
✕ Don't
  • Recolour the monogram to anything but the brand gradient
  • Rotate, skew, mirror or outline the mark
  • Swap the rounded caps for square or butt caps
  • Remove or move the centre node — it is the AI layer
  • Stretch to a non-proportional aspect ratio
  • Add a drop shadow or glow directly to the mark

Change only the width and height. Everything else is fixed.

🔒
Why 0.367em and not a rounder number

That value was measured from the rendered font, not guessed. Both lines are sized in em so the match holds at every breakpoint and at any root font size.

⚠️
The font-size ratio is just as load-bearing as the tracking

0.367em is only correct in combination with a line-2 font size of 0.9em. The two are a matched pair.

Set line 2 to an absolute pixel value — say 14px under a 20px parent, a ratio of 0.7 — and keep the same 0.367em, and the lockup visibly breaks: SOLUTIONS comes out about 34px short at that size. The tracking must be expressed in em so it scales with whichever ratio you choose.

This is why the container uses align-items: flex-start: it lets each line shrink to its own text, which is what makes the two widths comparable at all. A block-level child would stretch and hide the problem.

⚠️
Important: two slightly different colour sets exist

Colours written in source (the logo gradient, the light-mode overrides in globals.css) use canonical values: #10B981, #06B6D4, #020617, #0f172a, #1e293b, #cbd5e1.

Colours emitted by the build for utilities such as bg-emerald-500 are marginally shifted: #00BB7F, #020618, #0F172B, #1D293D, #CAD5E2.

The difference is at most a few units of blue and is invisible in practice — but if you sample a colour from the rendered site with an eyedropper, you will get the second set. Use the source literals for anything you design outside the site.

How much of each
  • 60% slate — the canvas, cards, borders, body text

The single most important typographic setting

The site root font size is 18px, not the browser default of 16px. Because every Tailwind size is in rem, this scales the entire site's text by +12.5% in one place.

To retune readability site-wide, change that one number in globals.css and nothing else.

10 Motion

Fast and functional. Nothing bounces, nothing delays a user's action.

DurationUsed for
150msOption selection, checkbox toggle, small state changes
200msBorder and colour transitions, button hover
300msTheme switching, logo hover, menu drawer
80msTypewriter — one character typed
40msTypewriter — one character erased (2× faster, as humans backspace)
2000msTypewriter — pause on a completed word so it can be read
1000msCursor pulse, looping

Interaction responses

  • Press: active:scale-95 on buttons, active:scale-98 on cards, active:scale-90 on the theme toggle
  • Logo hover: scale-105; the wordmark shifts to emerald
  • Link hover: colour shift only — no underline in the site chrome, underline in prose
  • Easing: default. No custom cubic-bezier except the toast
⚡
Transitions must never be disabled

A global rule applies a 200ms transition to background, border, colour and shadow on every element. Removing it causes visible flicker when the theme toggles.

12 Design tokens

The primitive layer. These are raw values with no meaning attached — a colour called 500, not button-fill. The meaning arrives one section later.

🧱
Why the two layers exist

Primitives are the palette. Semantic tokens are the decisions — “the background of a card”, “the text of a caption”.

Re-theming means rewriting only the semantic layer. The primitive palette never moves, so nothing downstream breaks.

Naming convention

Pattern
--{category}-{role}-{variant}
Category
color · space · radius · shadow · font · size · motion · z · border
Role
What it is for (canvas, surface, action, text, border)
Variant
Scale step or state (500, strong, hover, active)
Case
Lowercase, hyphenated, never abbreviated beyond the list above
Prohibition
No colour names in semantic tokens — never --green-button

The single most important design-system rule here

--color-text-caption is #62748E in dark and #475569 in light — both fail or barely pass AA for body text.

It exists only for timestamps, footnotes and legal lines at 16px or larger. Never use it for a sentence someone has to read to act.

One caveat about reusing that SVG twice

SVG ids are document-scoped. If the same logo appears more than once on a page, the second instance must use a different gradient id (dosMark → dosMark2) in both the linearGradient and its url() reference, or the first definition will silently win.

Rules

  • Never mix icon families. Lucide only.
  • Never hardcode an icon colour — always inherit the surrounding text colour, or set it explicitly to an accent token.
  • Icons paired with text sit at gap-2 or gap-2.5.
  • Decorative icons take aria-hidden="true". Meaningful standalone icons need an aria-label.
  • Icon sizes are odd values on purpose (w-3.5 = 14px, w-5 = 18px at this root) so they align optically with the type scale.

Non-negotiable accessibility requirements
  • Body text meets at least 4.5:1. Only the ratios in section 05 qualify.
  • Every input has a real <label>, not a placeholder doing a label's job.
  • Focus is always visible and never removed without an equal replacement.
  • Colour is never the sole carrier of meaning — pair it with an icon, weight change or border.
  • The theme toggle announces itself via aria-label, and client-rendered icons wait for mount to avoid a hydration mismatch.

18 Rules of the road

If you remember nothing else, remember these fourteen.

  1. Use the provided SVG logo. Never redraw, recolour or restyle it.
  2. The signal colour is emerald #10B981 and cyan #06B6D4. Nothing else is a brand colour.
  3. Slate carries everything neutral. The canvas is #020617.
  4. Accent colour on no more than a couple of elements per screen.
  5. Two type families only: Geist Sans and Geist Mono.
  6. Never render text below 11px.
  7. Headlines are tight (-0.025em); labels are wide (+0.05em).
  8. rounded-xl is the default radius. Reach for something larger only for a genuinely distinct surface.
  9. Depth comes from borders and bloom, not heavy shadows.
  10. One icon family: Lucide, inheriting currentColor.
  11. Components consume semantic tokens, never primitives.
  12. Every interactive element declares all four states, including focus-visible.
  13. Never rely on colour alone to carry meaning.
  14. State a price or timeline only through the estimator, never as a hand-written claim.
